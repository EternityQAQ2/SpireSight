## 已应用的运行配置

通过 CLI 使用 DeepSeek 官方地址时，默认启用自适应思考：精英、Boss 或至少两个存活敌人的战斗开启 thinking，其余局面关闭。思考请求的输出上限至少4096，普通请求沿用原配置；两轮工具预算及现有失败处理不变。4096仍可能耗尽，不能保证必然返回决策。

设置 `OPENAI_ADAPTIVE_THINKING=false` 可关闭自动切换，恢复使用 `OPENAI_THINKING`。其他服务默认不开启此功能，避免向不支持的 API 发送 thinking 参数；直接构造模型对象时可显式传 `adaptive_thinking=True`。每次请求按当前局面计算模式，不修改共享模型配置，日志记录实际模式及输出上限。
