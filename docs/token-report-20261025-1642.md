## 2. 两项优化的实战验证

**① 战斗证据去重（生效）**：全部 30 次战斗请求的 SQLite 证据只有 `relics`（缚魂圣物）、`powers`（饥饿）、`interactions`（效果交互）——**`sqlite:cards:*` 出现 0 次**。卡牌信息完全由冻结图鉴供给，4 个证据槽位让给了遗物/敌人/交互与攻略种子。

**② 地图瘦身（生效，收益打折）**：地图 prompt 从 5,392-6,008 字符降到 3,521-3,891（**-35% 字符**）；但 tokens 只从 ~2,639 降到 ~2,115（**-20%**）——数组编码里数字和括号的 token 密度比中文高（`[3,16,"Boss",[[0,15]]]` 比等长中文更费 token）。这是用信息零损失换来的，若要进一步压缩需改为语义裁剪（只保留 2 层前瞻），会牺牲长线规划，暂不建议。
