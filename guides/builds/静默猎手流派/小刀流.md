# 小刀流
[小刀流](https://slaythespire2.net/zh-CN/build/silent?v=beta#build-shiv)

- 角色：静默猎手
- 评级：A级

用 0 费的小刀塞满手牌，再强化每一把小刀和所有计算攻击次数的遗物。

## 玩法思路
前期靠刀刃之舞、斗篷与匕首、先制打击打出快速的前期伤害。撑到后面几幕要靠精准与无尽刀刃；刀扇让小刀变成群体伤害，余像、苦无或精致折扇则把大量攻击转成防御。

## 优点
第一幕就容易成形、前期伤害强，许多依攻击次数触发的遗物能让输出翻倍。

## 缺点
大量小额伤害遇到敌人的格挡会大打折扣；没拿到精准或关键遗物的话，第三幕会后继无力。

## 评级原因-A
小刀是 0 费，刀刃之舞和斗篷与匕首让它拥有静默猎手各卡组中最强的第一幕伤害，计算攻击次数的遗物还能再往上叠。但后期几乎全看精准：没有它，每刀伤害太低，打不穿格挡和第三幕首领，所以是 A 不是 S；和奇巧弃牌流同级，只是用较低的上限换来更容易上手的开局。

## 核心卡牌
刀刃之舞、精准、无尽刀刃、斗篷与匕首、先制打击

## 辅助卡牌
刀扇、幻影之刃、墨之刃、刀刃陷阱、钢铁风暴、隐秘匕首、余像、终结技、暴露

## 关键遗物
忍术卷轴、螺线飞镖、苦无、手里剑、精致折扇、双截棍
