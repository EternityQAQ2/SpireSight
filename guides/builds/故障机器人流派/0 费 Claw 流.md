# 0 费 Claw 流
[0 费 Claw 流](https://slaythespire2.net/zh-CN/build/defect?v=beta#build-claw-zero-cost)

- 角色：故障机器人
- 评级：A级

狂打 0 费攻击，核心是每打出一张 Claw 就让所有 Claw 伤害提高的爪击。

## 玩法思路
拿爪击以及刮削、超越光速这类便宜的过牌，保持卡组精简。野性每回合把一张 0 费攻击拿回手牌，万物一心把弃牌堆所有 0 费牌拿回来打出爆发回合。

## 优点
故障机器人所有卡组中伤害上限最高，完全不需要集中。

## 缺点
依赖万物一心、野性等特定罕见/稀有牌；格挡少，卡组一臃肿就会崩。

## 评级原因-A
爪击本身是普通的 0 费牌，但这套牌要等野性和万物一心到手，才能打出故障机器人最高的伤害上限，过程中格挡也很少。成形时比冰霜更强，但稳定性差很多，所以低一级排在 A。

## 核心卡牌
爪击、万物一心、野性、刮削、超越光速

## 辅助卡牌
光束射线、眼部攻击、快速检索、全息影像、趁势打击、适应打击、暴涨、热修复、亮剑

## 关键遗物
不休陀螺、手里剑、苦无
