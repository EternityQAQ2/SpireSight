# 女王

[女王](https://sts2.huijiwiki.com/wiki/女王)

荣耀阶段 Boss。女王生命值 400（进阶 8+ 为 419），开场带一只爪牙【火炬头聚合体】，生命值 199（211）。

## 战斗循环

### 女王

阶段一（聚合体存活）：

提线木偶（仅第 1 回合） → 你是我的了（仅第 2 回合） → 为我尽力燃烧吧 → 为我尽力燃烧吧 → …

阶段二（聚合体死亡后）：

激怒（立即触发） → 将头砍下 → 处决 → 激怒 → …

### 火炬头聚合体

冲撞 → 冲撞 → 光束 → 冲撞（弱） → 冲撞（弱） → 光束 → …

## 机制

**聚合体在场时女王不攻击。** 她只负责支援：给聚合体 +1 力量、给自己 +20 格挡。聚合体死亡后女王才进入攻击形态。

**魂缚锁链**：每回合抽到的前 3 张牌会被侵蚀为「魂缚」，等于前 3 张抽牌不可用，依赖关键牌的 combo 会被打乱。

**99 层脆弱/虚弱/易伤是永久负面**：你的格挡牌 -25% 格挡、攻击 -25% 伤害、受到的攻击 +50%。整场都不会消失。

**聚合体死亡会立刻进入女王阶段二**：她获得 2 点力量，然后才开始攻击。

## 策略（推断，非 Wiki 原文）

> 以下策略由上文的行为和机制推导，不是 Wiki 原文，按牌组实际情况判断。

**聚合体必须在它叠起力量前处理掉。** 女王从第 3 回合起每回合给它 +1 力量，拖得越久冲撞/光束越痛。

**但也不要无脑速杀聚合体。** 女王每回合给自己 +20 格挡，聚合体活着时她很难被打；正确顺序是先解决聚合体，再转火女王。

**聚合体死亡的那回合是白给回合。** 女王会用「激怒」而不是攻击，利用这一回合铺格挡或上力量，准备迎接下一回合的 将头砍下/处决。

**99 层易伤意味着所有伤害 ×1.5。** 处决 15/18 实际是 22/27，将头砍下 15/20 实际是 22/30；格挡要按放大后的数值留。

**魂缚锁链让前 3 张抽牌不可用**，所以不要依赖“抽到某张关键牌”的固定 combo，能量和手牌要留冗余。

**这场是限时战**：永久负面 + 女王叠力量 + 聚合体叠力量，拖久了必输。
