# 实验体

[实验体](https://sts2.huijiwiki.com/wiki/实验体)

荣耀阶段 Boss。分三个阶段，生命值分别是 100 / 200 / 300（进阶 8+ 为 111 / 212 / 313）。

初始能力：
- **适者生存**：当它将要被击败时，会复活并变得更强。
- **激怒**：每当你打出一张技能牌，它获得 2 点力量（高进阶为 3 点）。

## 战斗循环

阶段一（100/111 血，自带 3 层激怒）：噬咬 → 颅骨重击 → 噬咬 → …

阶段二（200/212 血，自带 1 层疼痛戳刺）：多次爪击 → 多次爪击 → …

阶段三（300/313 血，自带天罚）：撕碎 → 大力猛扑 → 燃烧之吼 → 撕碎 → …

每次阶段血量耗尽后，会使用一次「重生」：跳过一回合，回满下一阶段生命，清除上一阶段的所有状态。

## 机制

**三阶段连战，重生不继承状态。** 每次复活都会清除它身上的所有负面（包括激怒叠出的力量、遗物给的力量），并回满血。所以不要把关键 debuff 或爆发提前交在阶段末尾。

**激怒是核心惩罚。** 你每打出一张技能牌，它就 +2/+3 力量。防御牌大多是技能牌，所以“堆格挡”本身会让它越来越强。

**阶段二的疼痛戳刺**：每次你受到未被格挡的伤害，就把 1 张「伤口」洗进弃牌堆——挨打会污染牌组。

**阶段三的天罚**：每两个回合结束时获得 1 层无实体，也就是隔一回合你的伤害会被降到 1。

**重生回合它不攻击**，是白给的一回合，但指定敌人的牌和药水在这一回合无法使用。

## 策略（推断，非 Wiki 原文）

> 以下策略由上文的行为和机制推导，不是 Wiki 原文，按牌组实际情况判断。

**尽量少打技能牌。** 每一张技能牌都是给它 +2/+3 力量；能用攻击牌解决的回合就不要顺手开技能。需要格挡时优先用攻击附带的格挡或遗物格挡。

**每个阶段都按“限时爆发”打。** 阶段二每回合多一段爪击，阶段三有 45 点猛扑，拖得越久越不可能赢。

**阶段三看天罚的无实体。** 无实体回合你的输出只有 1，把爆发留到没有无实体的回合，不要在无敌回合浪费大招。

**重生回合用来铺场**，但不要提前上易伤/虚弱——重生会清掉。

**阶段二挨打会塞伤口**，尽量用格挡吃满伤害，减少未被格挡的损失，避免牌组被伤口淹没。

**大力猛扑 45 点是全场最高单次伤害**，这一回合必须留足格挡。
