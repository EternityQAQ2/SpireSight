# 第二幕 Boss 备战

[第二幕 Boss 备战](https://www.spirebuilds.com/guides/slay-the-spire-2-all-bosses-guide#act-2-hive)

到第二幕，"我有伤害"不再是一个完整的计划。牌组需要抽牌质量、成长能力，或足够的格挡重复——一次糟糕的洗牌不应该演变成药水危机。

各 Boss 暴露的弱点：
- 碾碎爪：暴露在推进获胜条件的同时无法覆盖重复压力的牌组。
- 知识恶魔：暴露诅咒处理糟糕、被干扰时手牌失去功能的牌组。
- 火箭：暴露对明示的爆发回合缺少答案的牌组。
- 无厌沙虫：暴露续航弱、伤害慢、或对其重复攻击序列没有计划的牌组。

不要因为压力就见防御牌就拿。改进的是让现有引擎准时发生的那张牌：抽牌负责找到答案，能量负责打出答案，删牌负责提高答案出现的概率。
